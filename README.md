## Edição gratuita

- **3 tarefas simultâneas**; solicitações adicionais aguardam na fila.
- **3 workspaces**, incluindo o workspace inicial.
- **15 tarefas no total**, compartilhadas entre todos os workspaces. Rascunhos, modelos e tarefas pausadas contam no limite.

Ao atualizar, todos os dados são preservados. Os **3 workspaces e as 15 tarefas mais antigos** têm prioridade. Uma tarefa precisa atender aos dois limites para executar. Excedentes continuam disponíveis para consulta, edição e exclusão de tarefas, mas não executam manualmente nem pelo agendador. Excluir uma tarefa libera sua posição para a próxima mais antiga; agendamentos preservados podem voltar a executar quando elegíveis. Não há exclusão de workspace nesta versão.

Os limites valem a partir da versão 1.0.5. Versões anteriores já distribuídas não são alteradas.

## Instalação

1. Baixe o instalador correspondente ao seu computador.
2. No Windows, abra o arquivo `.exe` e siga o assistente. No Mac, abra o `.dmg` e arraste NX Schedule para Aplicativos.
3. Em **Configurações → Aparência e tamanho → Idioma**, escolha **Português (Brasil)** ou **English (United States)**.

## Requisitos e funcionamento

- macOS 15 ou superior. Escolha Apple Silicon ou Intel conforme o processador do Mac.
- O aplicativo precisa permanecer aberto e o computador ligado e acordado para executar agendamentos.
- JavaScript usa o Node.js incluído. Outras linguagens exigem seu interpretador instalado.
- Atualização nativa de planilhas Excel exige Windows e Microsoft Excel desktop. No Mac, use scripts personalizados.
- Os instaladores ainda não possuem assinatura comercial; os aplicativos Mac têm assinatura ad-hoc, sem notarização Apple.
